# Recipes

This directory holds Curadh Cooking recipe artifacts.

## Status

- **Draft** — formula exists but has not been cooked/tested.
- **Tested** — at least one documented kitchen test occurred.
- **Canonical** — Jim approved it as the current project version.

## Minimum useful recipe record

A mature recipe should capture, as applicable:

- title and version/status;
- yield;
- ingredient quantities and forms;
- tools/pan;
- active and total time;
- temperature;
- ordered method;
- doneness cues;
- substitutions;
- nutrition data/source when used;
- profile-fit notes with provenance;
- test observations;
- source/attribution.

Recipe 0001 will establish the practical template rather than forcing an abstract schema first.
